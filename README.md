# Lisandro Murúa Asis — Portfolio web

Sitio estático (HTML + CSS, sin build) con portfolio, servicios de diseño y vías de contacto.

- `index.html`: la página completa.
- `assets/img/`: imágenes de proyectos.
- `assets/favicon.svg`: ícono del sitio.

## Publicar con GitHub Pages

1. Subir este contenido a la rama `main` del repositorio.
2. En **Settings → Pages**, elegir *Deploy from a branch* → `main` / `(root)`.
3. El sitio queda en `https://<usuario>.github.io/<repo>/`.
